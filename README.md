# F-150 5.0 Live Dash

Live OBD2 dashboard for a 2017 F-150 5.0 (6R80). Open https://y5oi.github.io/f150-dash/ :

- **iPhone:** in the Bluefy browser (Safari can't use Bluetooth). Connects to a Bluetooth LE adapter such as the UniCarScan UCSI-2100.
- **Laptop:** in Chrome or Edge. Bluetooth LE adapter, or a USB ELM327 cable (close FORScan first).

Read-only: it never clears codes or writes to the truck. Without an adapter it replays a recorded drive.
